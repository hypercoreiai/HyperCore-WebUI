- TTL is the hard constraint (an absolute deadline on `time.monotonic()`); LFU is the secondary policy, invoked only when the cache is full and nothing has expired.
- `set(_store) == set(_freq) == set(_ttl)` — no orphan in any tier 3.
- A key returned by `get()` is the same value written by the most recent `set()` Concurrency model.
- `RLock` rather than `Lock` because the purge helper is re-entered from `get()`/`set()` on the same thread.
- `time.monotonic` is bound as `self._clock` so the clock is injectable for testing.
- Known trade-off (flagged, not hidden): `min(self._freq, key=self._freq.get)` is O(n) per insert.
- I instrumented the identical code path with a stall in the unlocked window so the schedule is reproducible rather than luck-dependent (`trace.py`, actual output): What the pointer state is doing.

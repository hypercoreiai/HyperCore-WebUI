MCP servers

Their tools run on this PC with your rights, when the model decides to call them (in this page's chat only; switch it off in Sampling). Each switch turns that server off without reloading the model.

External assistants

Every Assist request and every "Check lag" probe is written to a small log so this card can show what was sent and what came back. The models that were timed but not pinned are listed with their lag, which is why a model can be on the endpoint and still absent from the dropdown.

Chat history

The archive button on the Chat tab writes a transcript to data/history/_old_chats/; tools/build_history.py distils the transcripts into chats/, topics/ and notes/. Archiving starts that rebuild on its own; this button runs it without waiting for a chat.
